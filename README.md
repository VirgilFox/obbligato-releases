# Obbligato releases

Download links for [Obbligato](https://github.com/VirgilFox/SheetMusicApp), a sheet music
reader for e-ink tablets. **Binaries only — no source code lives here.**

`latest.json` is what installed copies of the app read to discover updates. It is fetched
from `raw.githubusercontent.com`, so it must stay on the default branch at the repo root.

The app is free to download and use for up to 7 pieces; a license removes that limit.
